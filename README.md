# 离线专家库系统V3

离线专家库系统V3是一个基于Web的本地离线应用系统，主要用于专家信息管理和专家组名单维护。系统采用纯前端技术实现，使用IndexedDB作为本地数据库存储，无需后端服务器支持。

## 功能特点

- 专家信息管理（增删改查）
- 专家分类（内部专家/外部专家）
- 专家组名单随机抽取
- 指定专家设置
- 数据导入导出（Excel/JSON格式）
- 本地数据备份
- 基于机器码的许可证授权机制
- 多用户角色权限控制

## 技术架构

- 前端框架：原生JavaScript
- 数据存储：IndexedDB
- 表格处理：xlsx.js库
- 样式设计：CSS3 + HTML5
- 加密工具：CryptoJS（Argon2算法）

## 系统角色

1. **管理员**（zjk_admin/zjk_admin）
   - 拥有所有功能权限
   - 可管理专家库、指定专家、专家组名单等

2. **维护员**（zjk_wh/zjk_wh）
   - 可维护专家库和专家组名单
   - 无法设置指定专家

3. **专家用户**（zjk/zjk）
   - 只能查看专家组名单

## 核心功能模块

1. **用户登录认证**
   - 基于用户名密码的身份验证
   - 多角色权限控制

2. **授权许可证管理**
   - 基于机器码识别的许可证验证机制
   - 支持试用、个人、企业、永久等多种授权类型
   - 提供许可证导入激活功能

3. **专家信息管理**
   - 专家信息的增删改查操作
   - 支持内部专家和外部专家分类
   - 支持Excel导入导出和数据备份

4. **专家组名单管理**
   - 按指定数量随机抽取专家组名单
   - 支持分别设置内部和外部专家数量
   - 可导出专家组名单为Excel文件

5. **指定专家管理**
   - 设置和取消指定专家
   - 在专家组抽取时可优先包含指定专家

## 使用说明

1. 打开 `index.html` 进入登录页面
2. 使用系统预设账号登录：
   - 管理员：zjk_admin / zjk_admin
   - 维护员：zjk_wh / zjk_wh
   - 专家用户：zjk / zjk
3. 登录后根据用户角色使用相应功能

- Edge（Chromium 内核）79+
- Edge（旧版，EdgeHTML 内核）12+
- Safari 8+
- Opera 15+
- Android 浏览器 4.4+
- iOS Safari 8+
- 360浏览器等基于Chromium内核的浏览器
